My focus spans full-stack development, Agentic AI, and MLOps. I'm interested in the engineering that makes AI useful in real products: connecting models to business data and tools, automating workflows, and building services that are reliable, observable, and maintainable.

### What I work on

- Full-stack applications: Web interfaces, backend APIs, authentication, and integrations using React/Next.js, Vue/Nuxt, Go, NestJS, and FastAPI.

- Applied AI: RAG assistants, LLM integrations, conversational systems, and facial-recognition services.

- Backend and cloud engineering: Event-driven workflows, asynchronous processing, real-time communication, and deployments on AWS and Google Cloud.

- Agentic AI and MLOps: A focus on tool-using agents, reproducible data and ML workflows, evaluation, deployment automation, and monitoring.
